Mandata for Windows

A zip of install scripts, not a setup program. Nothing to sign, nothing that needs an administrator. It runs on a standard work laptop with Windows 10 or 11 and classic Outlook.

Install

Four steps

  1. Unblock the zip

    Right-click the downloaded zip, choose Properties, tick Unblock, then OK. This stops Windows asking again for each script.

  2. Extract it

    Right-click, Extract All. Open the Mandata-Installer folder it makes.

  3. Double-click install.bat

    It checks the laptop, downloads the app runtime from GitHub (checked against its published SHA-256), copies the app to %LOCALAPPDATA%\Programs\Mandata and adds Start Menu and Desktop shortcuts.

  4. Say yes to the local AI

    It offers to install Ollama and the model that best fits your laptop's memory and graphics card, a 3 to 20 GB download. Then Mandata starts and reads the last 30 days of mail.

Updating: download the new zip and run install.bat again. Your data in %USERPROFILE%\.mandata is never touched by an update.

Requirements

What the laptop needs

WindowsWindows 10 or 11, 64-bit (x64 or ARM64)
OutlookClassic Outlook, signed in. The new Outlook does not offer the connection Mandata reads mail through.
RightsNone beyond a normal user account. PowerShell scripts must be allowed to run.
DiskAbout 0.8 GB for the app, plus the AI model's size and 2 GB (about 5 GB for phi4-mini).
Memory8 GB works; 16 GB or a separate graphics card reads mail much faster.
InternetOnly during install, to reach GitHub and Ollama. Reading mail is offline.

Prefer the command line? Options go after install.bat: -AI no skips the AI, -Model qwen3:8b picks a model, -NoDesktopIcon, -NoLaunch.

If something goes wrong

Troubleshooting

The scripts don't run, or "ConstrainedLanguage mode"

An IT policy blocks PowerShell scripts on this laptop. Ask your IT service desk to allow them, or to run the installer for you.

Mandata.exe is blocked from starting

Some policies (AppLocker) allow programs only from Program Files. Ask IT to allow %LOCALAPPDATA%\Programs\Mandata\Mandata.exe. A code-signing certificate would not change this.

A download fails

Check the internet connection or VPN. The installer uses the Windows proxy settings and signs in to the proxy as you. Run install.bat again and it continues where it stopped.

"Could not replace ..."

Quit Mandata from its tray icon (right-click, Quit) and run install.bat again.

Windows says "Windows protected your PC"

The zip was not unblocked before extracting. Click More info, then Run anyway, or delete the folder, unblock the zip (step 1) and extract it again.

How do I uninstall?

Settings, Apps, Mandata, Uninstall, or double-click uninstall.bat. It asks before removing your data or the AI model; both are kept by default.

Can I pin it to the taskbar?

Windows lets no installer do that. While Mandata runs, right-click its taskbar icon and choose Pin to taskbar.
