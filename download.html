Install

Three steps

  1. Double-click Mandata-Windows.exe

    Windows may say "Windows protected your PC", as it does for any program without a publisher's certificate: click More info, then Run anyway. No administrator rights are asked for.

  2. Let it install

    A window shows each step. It checks the laptop, downloads the app runtime from GitHub (checked against its published SHA-256), copies the app to %LOCALAPPDATA%\Programs\Mandata and adds Start Menu and Desktop shortcuts.

  3. Say yes to the local AI

    It offers to install Ollama and the model that best fits your laptop's memory and graphics card, a 3 to 20 GB download. Then Mandata starts and reads the last 30 days of mail.

Updating: Mandata updates itself (Settings > Updates), or run the new installer. Your data in %USERPROFILE%\.mandata is never touched by an update.

If something goes wrong

Troubleshooting

The scripts don't run, or "ConstrainedLanguage mode"

An IT policy blocks PowerShell scripts on this laptop. Ask your IT service desk to allow them, or to run the installer for you.

Mandata.exe is blocked from starting

Some policies (AppLocker) allow programs only from Program Files. Ask IT to allow %LOCALAPPDATA%\Programs\Mandata\Mandata.exe. A code-signing certificate would not change this.

A download fails

Check the internet connection or VPN. The installer uses the Windows proxy settings and signs in to the proxy as you. Run the installer again and it continues where it stopped.

"Could not replace ..."

Quit Mandata from its tray icon (right-click, Quit) and run the installer again.

Windows says "Windows protected your PC"

Mandata has no publisher's certificate, so Windows SmartScreen asks once. Click More info, then Run anyway.

How do I uninstall?

Settings, Apps, Mandata, Uninstall. It asks before removing your data or the AI model; both are kept by default.

Can I pin it to the taskbar?

Windows lets no installer do that. While Mandata runs, right-click its taskbar icon and choose Pin to taskbar.

macOS and Linux

Questions

How does Mandata read my mail without Outlook for Windows?

Through Microsoft 365, the service your Outlook mailbox lives in. You sign in once: Mandata shows a short code, you enter it at Microsoft's sign-in page in your browser, and Microsoft gives Mandata access to your mailbox. Mandata keeps that sign-in on your computer only (encrypted by the system keychain), and the AI that reads the mail still runs on your computer.

The sign-in says an administrator must approve it

Some organisations let only approved apps open mailboxes. Ask your IT service desk to approve access for Mandata, or to register an app for it in Microsoft Entra ID; they then give you an app ID, which you enter in Mandata's Settings > Mail.

Can I use a personal Outlook.com account?

Mandata is made for work and school mailboxes. To try a personal account, set the Microsoft 365 directory in Settings > Mail to common.

Mandata does not open on Linux

Install the libraries it uses. Debian or Ubuntu: sudo apt install libgtk-3-0 libnss3 libasound2 libgbm1 libxss1 libnotify4. Fedora: sudo dnf install gtk3 nss alsa-lib mesa-libgbm libXScrnSaver libnotify.

How do I uninstall?

Run curl -fsSL https://shamoug.github.io/mandata/install.sh | bash -s -- --uninstall. It asks before deleting your data, which is kept by default. A .deb is removed with sudo apt remove mandata; a .dmg install by moving Mandata to the Bin.

Does it start when I sign in to the computer?

Yes, from its first start, quietly in the background. Untick Open at login (macOS) or Start at login (Linux) in its tray menu to stop that.
