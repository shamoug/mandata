About the name
mandāta

Latin for "things entrusted": instructions given to someone to carry out.

manus hand+ dare to give→ mandare to place in someone's hand→ mandatum, pl. mandata

Every email that asks someone to do something hands them a mandatum. In a busy inbox those requests scatter across threads, folders and weeks, and the ones that matter most are often the ones nobody wrote down. Mandata finds each one and follows it to the end.

Why it exists

Task tools work only when someone types the task in. Most work in an office is asked for by email and never reaches a list. Mandata starts from the mail itself: it reads each thread whole, oldest message first, and keeps a running record of who owes what to whom.

It is built for organisations whose correspondence cannot be sent to an external AI service. The model runs on the laptop through Ollama. On Windows the app reads classic Outlook through its own local connection, and keeps working with the network cable removed; on macOS and Linux it fetches your mail from your own Microsoft 365 mailbox, and only the reading by the AI happens on the laptop.

How it is built

An Electron shell hosts a small Node.js server and a plain JavaScript interface, with no build step. Data lives in one relational SQLite file with enforced links and versioned upgrades, backed up before every upgrade. Every prompt the AI receives is visible and editable in Settings.

History

Version 1 was called Task Manager. Version 2.0 is the first under the name Mandata; installing it over version 1 updates it in place and keeps all its data. Version 2.2 brings Mandata to macOS and Linux, reading mail through Microsoft 365.
